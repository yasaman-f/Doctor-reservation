# نوبت‌یار — Frontend

کلاینت React برای سامانه نوبت‌دهی پزشک.

## هویت محصول

- زبان پیش‌فرض: فارسی
- جهت: RTL
- فونت: Vazirmatn
- طراحی: آرام، حرفه‌ای، مناسب خدمات سلامت ایران

## اسکریپت‌ها

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

## پروکسی توسعه

Vite مسیرهای `/auth`، `/doctor`، `/patient`، `/availability`، `/appointment` و `/socket.io` را به `http://localhost:3000` پروکسی می‌کند.
